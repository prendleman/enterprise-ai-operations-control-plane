# ADR 0001: Central AI Operations Control Plane

- **Status:** Accepted

## Context
Scattered AI experiments lack shared control and evidence.

## Decision
Implement a central control-plane prototype for intake, governance, registry, cost, and executive metrics.

## Alternatives Considered
Per-team spreadsheets; embed controls only in each app; buy an opaque SaaS without a reference model.

## Consequences
Shared lifecycle language and executable policies; local demo remains mock-first.

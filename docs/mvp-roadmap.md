# MVP Roadmap

## PHASE 0 — INVENTORY
Objective: discover shadow AI and subscriptions. Capabilities: survey + registry bootstrap. Owners: AO/PLT. Metrics: inventoried tools. Exit: baseline inventory accepted.

## PHASE 1 — INTAKE
Objective: one door for AI ideas. Capabilities: structured intake API/UI. Owners: AO/BO. Metrics: intake volume, completeness. Exit: intake mandatory for new work.

## PHASE 2 — GOVERNANCE
Objective: risk-based approvals. Capabilities: risk engine, policy, approvals. Owners: AO/SEC. Metrics: pending aging, block rate. Exit: HIGH/CRITICAL never auto-prod.

## PHASE 3 — SANDBOX
Objective: safe experimentation. Capabilities: sandbox eligibility, budgets, logging. Owners: PLT/AO. Metrics: active sandboxes. Exit: sandbox path documented.

## PHASE 4 — COST VISIBILITY
Objective: FinOps for AI. Capabilities: usage allocation, alerts. Owners: FIN/AO. Metrics: variance, alert response. Exit: monthly cost review live.

## PHASE 5 — AGENT REGISTRY
Objective: know what agents exist. Capabilities: registration, autonomy levels. Owners: AO/ENG. Metrics: registered agents, human-review coverage. Exit: unregistered agents disallowed in pilots.

## PHASE 6 — PRODUCTION CONTROLS
Objective: production readiness gates. Capabilities: checklist, reviews. Owners: AO/SEC/EA. Metrics: production approvals. Exit: checklist enforced.

## PHASE 7 — SCALE & OPTIMIZE
Objective: reuse and improve. Capabilities: templates, scorecards. Owners: AO/PLT. Metrics: reuse rate, cycle time. Exit: operating cadence stable.

# Adoption Framework

Stages: **EXPLORE → STANDARDIZE → PILOT → GOVERN → MEASURE → SCALE → OPTIMIZE**

## Explore
Office hours, use-case discovery workshops, executive sponsorship for a thin slice.

## Standardize
Shared intake, model catalog, risk language, success metric templates.

## Pilot
5–10 business-unit pilots with sandbox controls and named champions.

## Govern
Exception process, approval SLAs, restricted-data rules.

## Measure
Portfolio, cost, adoption, and outcome dashboards reviewed monthly.

## Scale
Reusable patterns, training paths, platform enablement.

## Optimize
Retire low-value use cases, tighten false-positive friction, improve model economics.

Feedback loops: champion forums, intake retrospectives, exception post-reviews.

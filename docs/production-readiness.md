# Production Readiness Checklist

Use before promoting a pilot to production eligibility:

- [ ] Business owner named
- [ ] Technical owner named
- [ ] Approved model/provider
- [ ] Approved data access / classification fit
- [ ] Risk assessment complete
- [ ] Security review complete (as required)
- [ ] Human review gates defined
- [ ] Structured logging enabled
- [ ] Cost budget and alert thresholds set
- [ ] Quality / outcome metric defined
- [ ] Rollback plan documented
- [ ] Support model assigned
- [ ] Monitoring / ownership for incidents
- [ ] Lifecycle review date scheduled

This checklist is an operating-model control for the reference implementation. Wire it to enterprise change systems in a real deployment.
